# Roadmap

## v0.1.x - tariff validation

- Collect anonymized real Kraken fixtures for Fixed, Go, Heat, dynamicOctopus, Intelligent Octopus Go 2024 and current Intelligent Octopus.
- Harden tariff mapper and DST behavior.
- Add diagnostics with automatic redaction.

## v0.2.0 - consumption and meters (completed)

- Electricity meter model and latest reading.
- Historical consumption coordinator.
- Preserve API interval lengths as returned by Kraken.

## v0.3.0 - SmartFlex foundation (completed)

- Device model and capabilities.
- Dispatches and charging sessions.
- EV / charge-point sensors.

## v0.4.0 - SmartFlex control (completed)

- Smart Control.
- Boost.
- Preferences / target time / target SoC where supported by the German API.

## v0.5.0 - gas

- Gas contracts, meters and readings.

## v1.0.0

- Stable tariff fixture matrix for supported German products.
- Stable entity model and migration documentation.
- Decision on long-term coexistence or migration from the older integration.
